== About the ESPD Demo Site

The https://docs.ted.europa.eu/espd-demo/[ESPD Demo Site] is a set of online tools that demonstrate how an ESPD Service works, built on the ESPD-EDM v5.0.0 model. It lets you explore the ESPD-EDM, download its distribution artefacts, and generate example ESPD Request and ESPD Response XML documents for testing.

[NOTE]
====
The ESPD Demo Site is provided for educational and testing purposes only. It is *not* a production ESPD Service: Member States must use the officially implemented ESPD services for their country.
====

== Who it is for

* *Buyers and policy officers* — to get familiar with the ESPD and what an ESPD Service offers before using one.
* *Developers and vendors* — as a reference while building an ESPD Service, and to produce valid example documents for testing.

== Tools available

[cols="1,3",options="header"]
|===
|Tool |Description

|Export artefacts
|Download the ESPD distribution files (code lists, model and data structure). Downloads can be filtered by ESPD-EDM version.

|Code lists
|Browse the code lists used in the ESPD: name, version, URI, agency, and links to more information. View the codes each list contains, with translations into all EU languages where available, and download each code list.

|eCertis integration
|Enter a criterion UUID directly or search the list, then check whether it is stored in eCertis. Every criterion in every ESPD version, from v1.0.0 onwards, can be queried.

|View the ESPD model
|See how a criterion in the ESPD-EDM might be represented in HTML within an ESPD Service. Individual criteria can be filtered by version and displayed on the page.

|Generate examples
|Produce example ESPD Request and ESPD Response XML files for chosen scenarios. These files are verified as correct so they can be used for testing without introducing errors of their own.
|===

=== Export artefacts
*Download the ESPD distribution files in Excel or XML format*

* The ESPD code list Excel and XML files
* The model and data structure Excel files

The downloads can be filtered by ESPD-EDM version.

=== Code lists
*Browse and download the code lists*

* Information about the code lists used in the ESPD: name, version, URI, agency, and links to more information for each list.
* The contents of each code list, i.e. the codes it contains, translations of each code into all EU languages (where available), and an XML download of each code list.

=== eCertis integration
*Check whether criterion UUIDs are stored in eCertis*

The UUID tool lets you enter a criterion UUID directly, or search for one via the list, and then check whether it is stored in eCertis. The list is ordered by ESPD version, then by ItemID, ascending. Every criterion in every ESPD version, from v1.0.0 onwards, can be queried.

=== View the ESPD model
*See how criteria elements might look in an online form*

The ESPD Model Viewer demonstrates how a criterion in the ESPD-EDM might be represented in HTML within an ESPD Service. Individual criteria can be filtered by version and displayed on the page.

=== Generate examples
*Generate example XML files for testing*

The Examples Generator produces example ESPD Request and ESPD Response XML files for chosen scenarios, which can then be used to test an ESPD Service implementation. These files are verified as correct so they can be used without introducing errors of their own into testing.

== Earlier ESPD-EDM versions

The ESPD Demo Site covers ESPD-EDM version 5.0.0 onward. For versions 4.1.0, 4.0.0, or 3.3.0, use the earlier https://docs.ted.europa.eu/espd-demo-v4/[ESPD Demo Site v4] (https://github.com/OP-TED/espd-demo-v4[source]).
