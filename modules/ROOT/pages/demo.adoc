== The ESPD Demo Site

The https://docs.ted.europa.eu/espd-demo-v4/[ESPD Demo Site] is a collection of online tools designed to help developers who are building or maintaining an ESPD Service. It lets you explore the ESPD-EDM, download its distribution artefacts, and generate example ESPD Request and ESPD Response XML files for testing.

[NOTE]
====
The ESPD Demo Site is provided for educational and testing purposes only. It is *not* an ESPD Service: Member States must use the officially implemented ESPD services for their country.
====

A description of the tools:

=== Distribution files
*Download the ESPD distribution files in Excel or XML format*

* The ESPD code list Excel and XML files
* The model and data structure Excel files

The downloads can be filtered by ESPD-EDM version.

=== Code lists
*Information about and download of code lists*

* Information about the code lists used in the ESPD: name, version, URI, agency, and links to more information for each list.
* The contents of each code list, i.e. the codes it contains, translations of each code into all EU languages (where available), and an XML download of each code list.

Code list information can be filtered by version and code list.

=== UUID
*Check whether UUIDs are stored in eCertis*

The UUID tool lets you enter a criterion UUID directly, or search for one via the list, and then check whether it is stored in eCertis by clicking the "Check eCertis" button. The tool queries eCertis to verify whether the UUID can be found.

The list is ordered by ESPD version, then by ItemID, ascending, and can be scrolled through to find the version and UUID you need.

Every criterion in every ESPD version, from v1.0.0 onwards, can be queried.

=== View
*See how criteria elements might look in an online form*

The ESPD Model Viewer demonstrates how a criterion in the model might be represented in HTML within an ESPD Service. Individual criteria can be filtered by version and are then displayed in HTML on the page.

=== Examples
*Generate example XML files for testing*

The Examples Generator allows developers to generate example ESPD Request and ESPD Response XML files, according to their chosen scenarios, that can then be used for testing their ESPD Service development. These XML files are verified as correct so they can be used without introducing errors of their own into testing.
