== ESPD Demo Site

The https://docs.ted.europa.eu/espd-demo/[ESPD Demo Site] is a set of online tools that demonstrate how an ESPD Service works, built on the ESPD-EDM v5.0.0 model. It is aimed at anyone who wants to understand or test the ESPD before (or while) implementing or procuring a service.

[NOTE]
====
The ESPD Demo Site is provided for educational and testing purposes only. It is *not* a production ESPD Service: Member States must use the officially implemented ESPD services for their country.
====

=== What you can do with it

* Explore how the exclusion grounds and selection criteria are structured.
* See how a criterion might appear to a user in an online ESPD form.
* Download the ESPD distribution artefacts (code lists, data structures).
* Generate example ESPD Request and ESPD Response XML documents to test an ESPD Service implementation.

=== Who it is for

* *Buyers and policy officers* — to get familiar with the ESPD and what an ESPD Service offers before using one.
* *Developers and vendors* — as a reference while building an ESPD Service, and to produce valid example documents for testing.

=== Open source

The ESPD Demo Site is open source, available at https://github.com/OP-TED/espd-demo[OP-TED/espd-demo] under the European Union Public Licence (EUPL) v. 1.2.
