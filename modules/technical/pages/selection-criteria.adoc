== Selection Criteria

[cols="1,4"]
|===
|*REQUIREMENT* |*The contracting body shall provide the exclusion grounds and selection criteria for its tendering process as structured information — via ESPD template or structured list of criteria set out in a call for tender.*
|===

As with the exclusion criteria, selection criteria are grouped under different categories. The figure below identifies and lists these categories for the selection criteria (branches in text boxes), and specific subgroups within each category.

Each branch in this 'criteria classification' corresponds to one data structure that is identical for all the leaves under that branch (e.g. compare the names of the boxes with the criterion type codes in the link:{url-tree}/codelists/ESPD-criterion.xlsx[ESPD-criterion data structures]).

== Lot Management approach for Selection Criteria

For Selection Criteria, the buyer may specify the Lots that apply to each selection criteria by using the element *cac:ProcurementProjectLotReference* inside the element *cac:TenderingCriterion*.

For details on lot management, see xref:lots-management.adoc[Lots Management].
