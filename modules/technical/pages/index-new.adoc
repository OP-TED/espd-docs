== Technical Implementation

This section provides technical documentation for developers implementing ESPD Services based on the ESPD-EDM v5.0.0 model.

It covers the architecture, the ESPD Request and Response documents, lot management, and the shared validation concepts. For criteria, model reference, and code lists, see the corresponding sections in the navigation.

=== Pages in this section

* xref:getting-started.adoc[Getting Started] +
Architecture overview, distribution package contents, repository structure, and first steps for implementers.

* xref:espd-request.adoc[ESPD Request] +
Technical guide to the ESPD Request document: schema, cardinality constraints, lot management, contracting party, and service provider.

* xref:espd-response.adoc[ESPD Response] +
Technical guide to the ESPD Response document: schema, economic operator party, criterion responses, and evidence.

* xref:lots-management.adoc[Lots Management] +
How lots are handled in both Request and Response, eForms alignment, and multi-lot response patterns.

* xref:common-concepts.adoc[Common Concepts] +
Shared technical patterns: Schematron architecture, validation life-cycle, and execution process.
